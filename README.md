# Food-waste-and-expiry-prediction-system
A Machine Learning project using Logistic Regression to predict food expiry risk based on food category, storage temperature, humidity, shelf life, and storage conditions. The model classifies food items as At Risk (1) or Not at Risk (0). Developed using Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn in Google Colab.
